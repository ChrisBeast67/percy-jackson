# Percy Jackson — The Camp Half-Blood Chronicles (unofficial fan site)

A fan website about **Rick Riordan's** Percy Jackson universe — the books, the camps, the characters, the gods — made by **Percy ⚡** for **The Beast**.

## What's inside

| Page | What it covers |
|---|---|
| `index.html` | Series overview, why you'll love it, where to start, on screen, by the numbers |
| `books.html` | Every series and novel in reading order, plus short stories and graphic novels |
| `camp.html` | Camp Half-Blood guide — cabins, arena, campfire, rules, Camp Jupiter |
| `characters.html` | The Big Three, Camp Half-Blood, the Seven, Trials of Apollo cast, mortals |
| `gods.html` | The Twelve Olympians, the big bads, monsters, other mythologies |
| `quiz.html` | 15-question lore quiz with demigod ranks |
| `parent-quiz.html` | "Which god is your parent?" personality quiz |

## Tech

Static HTML, CSS and vanilla JavaScript. No build step, no frameworks.

```
css/style.css      # deep sea / marble / gold theme
js/main.js         # scroll reveal + active nav
js/quiz.js         # lore quiz engine
js/parentquiz.js   # parent quiz engine
```

## Run it locally

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```
